2 Flashen & instellen
  1. Pi: Raspberry Pi Imager → "Gebruik eigen bestand" → het Pi-image → naar SD-kaart.
    Mini-pc: flash de installer-ISO naar een USB-stick (Imager/Rufus), boot de mini-pc ervan (evt. eenmalig in de BIOS: secure boot uit, USB-boot aan) - de machine installeert zichzelf volledig en wist daarbij de schijf.
  2. Printers via USB, netwerkkabel in de router, stroom erop. Eerste boot/installatie doet alles vanzelf (±5-10 min, internet vereist).
  3. Typ het IP in de browser → update-check → sleutel plakken (hierboven) → inloggen met admin → printers/lades kiezen. Het apparaat hernoemt zichzelf naar PA-{{ f.nummer }}-PLUSLokaal.
RMM automatisch mee-installeren (geldt voor alle winkels)

Plak het volledige Linux-installatiescript uit je RMM (of een one-liner). Elke nieuwe Pi voert dit bij de eerste boot uit. Het script wordt veilig in het image meegebakken (alleen admins kunnen dat downloaden). Na een wijziging: image opnieuw bouwen.

Alternatief: zelf Ubuntu flashen + bestand vervangen
  1. Flash Ubuntu Server LTS (64-bit) met Raspberry Pi Imager.
  2. Vervang op de schijf system-boot het bestand user-data door het bestand hieronder.
  3. Verder identiek aan stap 2 hierboven.
