2 Flashen & instellen
  1. Raspberry Pi Imager → "Gebruik eigen bestand" → het gedownloade image → flashen.
  2. Printers via USB, netwerkkabel in de router, stroom erop. Eerste boot installeert alles vanzelf (±5-10 min, internet vereist).
  3. Typ het IP van de Pi in de browser → update-check → sleutel plakken (hierboven) → inloggen met admin → printers/lades kiezen. De Pi hernoemt zichzelf naar PA-{{ f.nummer }}-PLUSLokaal.
RMM automatisch mee-installeren (geldt voor alle winkels)

Plak het volledige Linux-installatiescript uit je RMM (of een one-liner). Elke nieuwe Pi voert dit bij de eerste boot uit. Het script wordt veilig in het image meegebakken (alleen admins kunnen dat downloaden). Na een wijziging: image opnieuw bouwen.

Alternatief: zelf Ubuntu flashen + bestand vervangen
  1. Flash Ubuntu Server LTS (64-bit) met Raspberry Pi Imager.
  2. Vervang op de schijf system-boot het bestand user-data door het bestand hieronder.
  3. Verder identiek aan stap 2 hierboven.

Uitleg

Direct printen stuurt labels als {{ (f.printer_protocol or 'tspl')|upper }} rechtstreeks naar {{ f.printer_ip or '- geen IP -' }}:{{ f.printer_port or 9100 }}. TSPL print het volledige ontwerp (logo + barcode) als bitmap. De server verstuurt de print, dus de printer moet vanaf de server bereikbaar zijn. Komt er niets uit, kies dan een andere printertaal of gebruik browserprint.

De winkelprinter is de gewone kantoorprinter/copier (bv. Toshiba e-STUDIO) waar schapkaarten en scankaarten op afgedrukt worden, via IPP (poort 631) - geen apart stuurprogramma nodig. Kies per formaat welke papierlade gebruikt wordt; SK Mini en SK Middel zijn te klein voor deze printer en gebruiken altijd browserprint.
